# Epson Projector Tools

This repo contains tools for working with Epson projectors ESC/VP21 commands over serial, ESC/VP.net and HTTP interface.
The goal is to help with developing applications that communicate with Epson projectors.

> All tools are generated by AI. They have been manually tested and the basics seem to work fine.
> But be sceptical if things seem off, it is probably a bug.

## Command-line applications

### Projector Emulator

`epson-emulator` starts a projector emulator with serial TCP, ESC/VP.net and HTTP transports plus a Textual TUI.

Main features:

- Shared projector command engine and mutable projector state
- Projector model definitions in `models/`
- Emulator transports for serial TCP, ESC/VP.net and HTTP
- Password support for ESC/VP.net and HTTP, default password is "emulatorpassword"

### ESC/VP21 terminal

`epson-terminal` opens an interactive terminal client for sending commands to a projector or emulator.

- Interactive terminal client
- Connection presets for easy connecting to different devices
- Log of recent commands and connection changes
- Command history

## Dissectors for Wireshark

`/dissectors/escvpnet.lua` is a dissector for Wireshrak for the ESC/VP.net protocol.

## Documentation

- ESC/VP21 over HTTP protocol documentation reverse engineered from [epson-projector code](https://github.com/pszafer/epson_projector) and webinterface of LS11000W

## Quick start

To use the applications:

```bash
pip install -e .
```

Run the emulator:

```bash
epson-emulator
epson-emulator --password
epson-emulator --help
```

Run the terminal client:

```bash
epson-terminal
epson-terminal <connection-preset>
epson-terminal --help
```
